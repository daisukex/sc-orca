# SC-ORCA

**Space Cubics Open-Source Resilient Component Architecture**

SC-ORCA is an open-source collection of reusable RTL components
developed and maintained by Space Cubics.

It provides IP cores, bus components, primitives, packages, and
verification IP written in Verilog and SystemVerilog.

Space Cubics Inc. develops high-reliability computers for use in harsh
environments, including space. SC-ORCA publishes RTL components used
in our On-Board Computers (OBCs), together with common design
frameworks.

SC-ORCA follows design principles that account for the reliability
requirements of digital systems operating in space and other harsh
environments. These principles include fault-tolerance techniques such
as Triple Modular Redundancy (TMR) and error-correcting code (ECC),
along with measures to detect and mitigate logical faults caused by
Single Event Effects (SEEs), including Single Event Upsets (SEUs).
